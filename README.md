# Zomato-Food-Delivery-Website
A responsive Zomato-inspired food delivery website built using HTML and CSS, featuring a navigation header, hero section with background image, restaurant search bar, food delivery features, responsive design, and a clean modern UI.

🍴 Zomato Food Delivery Website

A Zomato-inspired food delivery website created using HTML and CSS. This project focuses on building a clean, modern, and responsive food delivery landing page with a Zomato-style design.

🚀 Features

- 🏠 Clean and modern homepage
- 🍴 Zomato-inspired UI
- 🔍 Restaurant, cuisine and dish search bar
- 🖼️ Hero section with background image
- 📱 Responsive design for different screen sizes
- ⚡ Fast Delivery feature section
- 🍕 Variety of Choices feature section
- 💳 Easy Payment feature section
- 🔗 Navigation links for Login, Signup, Add Restaurant and Investor Relations
- 📌 Simple footer section

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript for future functionality
